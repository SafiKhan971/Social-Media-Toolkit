# SMT Backend

Node.js + Express + MongoDB (local) backend for the SMT project.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy the example env file and fill in your values:
   ```bash
   cp .env.example .env
   ```

   - `MONGODB_URI` — defaults to `mongodb://localhost:27017/smt`. Make sure your local MongoDB server is running (`mongod` or `sudo systemctl start mongod`).
   - `HF_LOCAL_API_URL` — the URL of your local Hugging Face inference server (e.g. text-generation-inference running on your machine). Defaults to `http://localhost:8080`.
   - `HF_API_KEY` — only needed if your local server requires a token. Leave blank otherwise.

3. Start the server:
   ```bash
   npm run dev   # with nodemon, auto-restarts on file changes
   # or
   npm start
   ```

   Server runs on `http://localhost:5000` by default.

## API Routes

### Business CRUD

| Method | Route                  | Description          |
|--------|-------------------------|-----------------------|
| GET    | /api/businesses          | List all businesses   |
| GET    | /api/businesses/:id      | Get one business      |
| POST   | /api/businesses          | Create a business     |
| PUT    | /api/businesses/:id      | Update a business     |
| DELETE | /api/businesses/:id      | Delete a business     |

Request body for POST/PUT:
```json
{
  "name": "Business Name",
  "description": "Business description"
}
```

### Post generation

| Method | Route               | Description                          |
|--------|----------------------|----------------------------------------|
| POST   | /api/posts/generate   | Generate N posts for a business        |

Request body:
```json
{
  "businessId": "<mongo id>",
  "numberOfPosts": 3
}
```

Response:
```json
{
  "business": { "id": "...", "name": "..." },
  "posts": [
    { "imageUrl": "https://picsum.photos/seed/123/600/400", "caption": "..." }
  ]
}
```

Each post gets a random placeholder image from picsum.photos and a caption generated by calling your local Hugging Face inference server at `HF_LOCAL_API_URL`. If your local model server isn't running, caption generation for that post will fail gracefully — the image still comes back, and the error message is included on that post entry (plus a `warnings` array on the response) instead of failing the whole batch.

## Notes on the Hugging Face integration

This expects a local server exposing a `/generate` endpoint that accepts:
```json
{ "inputs": "<prompt>", "parameters": { "max_new_tokens": 60, "temperature": 0.8 } }
```
and returns either `{ "generated_text": "..." }` or `[{ "generated_text": "..." }]`.

This matches the typical shape of Hugging Face's `text-generation-inference` server. If you're running a different local server/model with a different request or response shape, adjust `generateCaption()` in `src/controllers/postController.js` to match.
